SEÇİLEN MODEL
faster-whisper · medium
✓
Türkçe konuşma tanıma
Model, Türkçe konuşmayı doğrudan yazıya dökebiliyor. Bu sayede Türkçe
anlatılan derslerde ek bir çeviri adımına gerek kalmıyor.
✓
Yerel ses işleme
Ses dosyası buluta yüklenmeden kullanıcının bilgisayarında işleniyor. Uzun
kayıtlar için hem gizlilik hem de API maliyeti açısından avantaj sağlıyor.
✓
GPU hızlandırması ve CPU yedeği
Whisper modeli, NVIDIA GPU desteği sayesinde kayıtları daha kısa sürede
işleyebiliyor. GPU kullanılamadığında uygulama otomatik olarak CPU üzerinde
çalışmayı deniyor.
✓
Özel akademik terim desteği
Derste geçen özel isimler ve terimler modele ipucu olarak verilebiliyor.
Böylece bu kelimelerin transkriptte daha doğru yazılması hedefleniyor.

01 Doğrudan soru sorma

02 Transkript tabanlı yanıt
üretimi
Gemini modeli, soruyu dersin zaman
damgalı transkriptiyle birlikte analiz eder.
Böylece cevapların ders içeriğine
dayanması hedeflenir.
03 Bilgi bulunamadığında
kontrollü yanıt
Prompt içinde modele, transkriptte olmayan
bilgileri genel bilgisiyle tamamlamaması
talimatı verilir. Cevap bulunamazsa
bulundu=false ile bu durum kullanıcıya
belirtilir.
04 Zaman damgalı kaynak
gösterimi
Sistem, cevabı en fazla üç kaynak
saniyesiyle ilişkilendirir. Kullanıcı bu
zamanlara tıklayarak ders kaydının ilgili
bölümünü yeniden dinleyebilir.
Gerçek “Soru sor” sekmesi: soru giriş alanı, “Sor” düğmesi ve üç önerilen soru.
Arayüz, cevapların yalnızca bu dersin transkriptine dayandığını kullanıcıya açıkça
belirtir.

Embedding vektörleri aracılığıyla

Girdi token sayısı transkriptin uzunluğuyla birlikte artıyor. En uzun kayıt olan Osmanlı Tarihi,

MALİYET FORMÜLÜ
( Girdi token / 1.000.000
× Girdi birim fiyatı )
+
( Çıktı token / 1.000.000
× Çıktı birim fiyatı )
Token nedir? Token, yapay zekâ modelinin metni işlerken
kullandığı küçük metin parçalarıdır. Girdi tokenları modele
gönderilen transkripti ve talimatları, çıktı tokenları ise modelin
ürettiği yanıtı ifade eder.
Yerel Whisper işlemi Gemini API maliyetinden ayrıdır; ses
dosyası için token harcanmaz.
API maliyeti, girdi ve çıktı token sayısının güncel birim fiyatlarla
çarpılmasıyla hesaplanır. Bu sunumda doğrulanmamış fiyat veya
dolar tutarı verilmemiştir.
