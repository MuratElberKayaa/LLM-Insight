Possible explanation (not verified):
Possible explanation (not verified): the call failed on its only stored attempt and was not retried, or its retries are not stored.
The recorded error.type is an HTTP 5xx status or openai.InternalServerError: the server that answered reported an internal failure. The stored data does not show whether that was the provider or a proxy, or whether other requests were affected; it does not establish a provider outage.
Not established by this data
The cause of the failure(s).
Whether the application retried the call: retries are recognisable only through llminsight.call_id and llminsight.attempt.
Whether a later attempt succeeded but has not been exported or stored.
Whether other requests or other projects were affected at the same time.
Limitations
error.type is a low-cardinality identifier chosen by the instrumentation; it is not verified against the provider.
Only spans stored at the time of this request are analysed; spans exported later, dropped by an exporter or rejected by the ingest are not visible.
The telemetry is reported real by the instrumentation; provenance is not cryptographically verified (provenance_verified is false).
Things a reviewer could check
Read the recorded error.type of the attempt in the evidence.
Check whether other traces in the same time window show failed attempts for the same provider and model (Trace Explorer, status filter).
Check whether the application retries this call; retries are not visible without llminsight.call_id.
Check the provider's status page for the time of the evidence; this platform cannot confirm an incident.
Not assessed by these rules
elevated latency
:
No approved comparison basis exists: the contracts define no latency objective or threshold (threshold alerts, M21, are P1), and a percentile of peer attempts would flag a fixed share of attempts by construction. Durations are reported as facts only.
semantic quality
:
Correctness, relevance and hallucination cannot be assessed from metadata: no prompt or completion is stored (ADR-19) and no evaluation result is linked to this trace.
prompt quality
:
Prompt content is never stored (ADR-19) and is not reconstructed.
provider outage
:
One trace cannot establish a provider-wide incident, and no provider status data is stored.
root cause
:
Findings are hypotheses; a root-cause decision needs human review (Failure Review, ADR-10).
